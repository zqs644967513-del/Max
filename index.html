DIRECTION A / MOTION SPECIFICATION

气泡提示 · 基线

沿用现有气泡语言，修正为指向夹板。文字最直接，但全屏变暗会暂时打断浏览。

用于评估现有气泡方案，不建议作为默认。遮罩覆盖信息较多，用户需要先阅读才能知道如何操作。
4.8s引导时间 / 建议值
0pt演示位移 / 建议值

01 / 动效节奏

遮罩 200ms 淡入，气泡位于夹板下方，尖角指向顶部夹板。4.2s 后淡出，4.8s 结束。

03 / 交互规则

  1. 触发条件：至少两张训练板，页面就绪 600ms，无其他弹窗或教学。首次可用时展示，单板不展示。
  2. 触摸夹板立即停止教学动效；上下方向由手势决定。原型拖动 50pt 提交，低于阈值回弹；完整切换 480ms。两类动画独立，教学不改变当前计划。
  3. 正文区域保留垂直滚动；只有顶部夹板与标题区 108pt 捕获切板。实际产品需排除“调整计划”等按钮的热区。
  4. 真实切板成功即记为完成。自动消失、短拖动或跳过仅记为本次结束，不记为学会。7 天内最多再展示一次。
  5. 系统减少动态效果时，取消位移示范，保留静态文案；切板用 120ms 淡入淡出。离线不影响本地引导。

DIRECTION C / MOTION SPECIFICATION

夹板轻拉回弹

前板轻拉 14pt 后归位，夹头边缘同步强调。让用户从真实物体的移动，理解这里可以滑动。

推荐作为默认。操作位置与提示一致，复用现有板子位移动效；不遮挡训练内容，也不会提前替用户切换计划。
4.8s引导时间 / 建议值
14pt演示位移 / 建议值
2 次单次出现内的动作次数

01 / 动效节奏

页面稳定 600ms 后，前板 0→14→0pt，后板同步补位 4pt；900ms 完成一次，停 300ms，重复一次。4.2–4.8s 收起提示。

01 / WHEN

首次可用，再出现

训练首页稳定 600ms、存在至少 2 张训练板且无其他引导时展示。只有一张板、加载中、弹窗中均不触发。

02 / INTERRUPT

触碰就停，操作优先

触摸板头立即取消演示，手势从静止基准跟手。正文的上下滑动保留给列表滚动，避免抢夺操作。

03 / COMPLETE

成功切换，结束教学

成功切板才记为已学会；关闭只结束本次。7 天内最多再提示一次，之后不自动出现；系统减少动态效果时改为静态提示。
